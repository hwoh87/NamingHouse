# name-stats — 출생신고 이름 순위·남녀비율 수집기

`engine/src/main/assets/name-stats.tsv` 를 생성한다.

```bash
python3 tools/name-stats/build_name_stats.py
```

파이썬 표준 라이브러리만 쓴다. 받은 원본은 `raw/` 에 캐시하므로 재실행 시 다시 받지 않고,
중간에 실패한 조회만 다시 시도한다.

## 출처

대한민국 법원 전자가족관계등록시스템 통계서비스 「상위 출생신고 이름 현황」
<https://stfamily.scourt.go.kr/st/StFrrStatcsView.do?pgmId=090000000025>

> 가족관계의 등록 등에 관한 법률 시행(2008. 1. 1.) 이후 조회일 현재까지 해당 지역의
> 가족관계등록관서를 통하여 출생사건이 접수된 후 가족관계등록부에 기록된 정보를
> 이름 순위로 집계한 일단위 통계 잠정치임(등록일 기준)

화면이 쓰는 WISE 리포트 조회를 그대로 사용한다.

```
POST /ds/report/query.do
  pid=1811 uid=999999 dsid=1261 dstype=DS sqlid=1811-1
  params={"@MultiCandType":{"value":["YY"]}, "@MultiCandStDt":{"value":["2024"]},
          "@MultiCandEdDt":{"value":["2024"]}, "@SidoCd":{"value":["11"]},
          "@GenderCd":{"value":["1"]}, "@CggCd":{...}, "@UmdCd":{...}}
→ {"data":[{"순위":1,"이름":"태오","건수":424,"전체비율":"태오(7.95%)"}, ...]}
```

세션 쿠키가 필요해서(없으면 빈 응답) 조회 전에 화면 URL 을 한 번 받아 둔다.
조회유형 코드는 `YY`=년도 / `YM`=년월 / `DT`=일자, 성별은 `1`=남자 / `2`=여자다.

## 이 데이터의 한계 — 읽기 전에 알아야 할 것

1. **한 조회에 상위 20개만** 돌아온다. 전국 순위는 16개 시도의 상위 20위를 합산한
   근사값이라, 어느 지역에서도 20위 안에 못 든 이름은 0건으로 집계된다.
   인기 이름 표시 용도로는 충분하지만 정밀 순위표가 아니다.
2. **시도가 필수이고 '전체' 선택지가 없다.** 그래서 16개 시도를 각각 조회해 합산한다.
   '(구)' 로 표기된 옛 행정구역 코드(부산직할시 등)는 중복 집계를 피해 제외했다.
3. **조회유형 '년도'는 시작~끝 범위가 2년 이내**여야 해서 한 해씩 조회한다.
4. 원 통계 자체가 **등록일 기준 잠정치**다.

19년 × 16시도 × 2성별 = 608회 조회. 요청 사이에 0.4초 쉰다.

## 출력 — `engine/src/main/assets/name-stats.tsv`

| 컬럼 | 설명 |
|---|---|
| `name` | 한글 이름 (1~3자, 한글만) |
| `dominant` | 더 많이 쓰인 성별 (M/F) |
| `maleCount` | 2008년 이후 남아 출생신고 건수 합 |
| `femaleCount` | 여아 건수 합 |
| `ranks` | 최근 6년 순위 `연도:순위` 콤마 구분 (dominant 성별 기준, 없으면 빈값) |

현재 213개 이름 / 최근 순위 보유 119개.

집계 예: 서준 38,961건(남 100%), 서윤 38,451건(여 100%), 지우 32,409건(남 432 / 여 31,977).

앱에서는 `NameStats` 가 읽어 추천 목록의 순위 칩과 상세의 「이름 통계」 카드에 쓴다.
파일이 없어도 앱은 통계 없이 정상 동작한다.
