# 작명왕 실측 리포트 (2026-08-11, name.sisomobile.com 무료 미리보기)

입력: 김(金) / 남자 / 2026-08-11 12:00 / 서울  — 우리 앱과 동일 조건
결과: 추천 가능한 이름 145개 (성씨별 풀 13,634개 중)

## 사주 — 우리 엔진과 완전 일치
작명왕: 丙午年 丙申月 丁巳日 丙午時
우리:   丙午   丙申   丁巳   丙午     ✓

오행 차트는 사주 8자(火7 金1) 위에 **이름 두 글자의 자원오행(木1 水1)을 얹어 10개로** 보여준다.
= 보완 전/후를 한 차트에 겹쳐 보여주는 방식. (우리는 사주 8자만 표시)

## 수리사격 — 공식이 우리와 동일 (허수 없음)
초년운 흥성격(31) / 청년운 발전격(18) / 장년운 성공격(29) / 전체운 안태격(39)

성 金=8획, 이름은 마스킹(**)이지만 4격에서 역산된다:
  정격 39 = 8 + 이름1 + 이름2      → 이름 합 31
  원격 31 = 이름1 + 이름2          ✓ 일치
  형격 18 = 8 + 이름1              → 이름1 = 10획
  이격 29 = 8 + 이름2              → 이름2 = 21획
  검산 10 + 21 = 31                ✓
→ 원=이름합, 형=성+이름1, 이=성+이름2, 정=총획. 우리 SuriCalculator 와 같다.

81수리 명칭 대조: 18 발전격 ✓ / 29 성공격 ✓ / 31 흥성격(우리 융창격) / 39 안태격(우리 안락격)
  → 2개는 이칭, 길흉 등급은 4개 모두 일치(전부 대길).

## 수리오행 — 계산법 역산 완료
표시: "수리 오행 매우 좋아요 / 金 水 木"
글자 3개(성+이름2)에 오행 3개 → **4격이 아니라 글자별 획수**를 오행으로 환산한다.
  金 8획  → 8 → 金   (7·8 = 金)
  이름1 10획 → 0 → 水 (9·0 = 水)
  이름2 21획 → 1 → 木 (1·2 = 木)
→ 끝자리 1·2=木 3·4=火 5·6=土 7·8=金 9·0=水, 글자마다 적용 후 발음오행과 같은 방식으로 상생 판정.
  金生水生木 = 연속 상생 → "매우 좋아요"

## 수리음양 — 우리와 동일
"음 음 양" = 8(짝=음) 10(짝=음) 21(홀=양). 획수 홀짝 기준 확인.

## 발음오행 — 운해본(다수설) 확인
"木 水 金" = 김(ㄱ=木) + 이름1(ㅁㅂㅍ=水) + 이름2(ㅅㅈㅊ=金)
→ ㅁ=水 이므로 운해본. 우리 기본값과 같다.
한자 픽커에서도 金의 발음오행을 木으로 표기(획수 8, 자원오행 金) — 우리 데이터와 일치.

## 점수 체계 — 100점 만점 없음
축마다 "매우 좋아요 / 보통" 같은 서술 등급 + 총평. 숫자 점수는 쓰지 않는다.
(우리는 100점 환산 — 하이작명 쪽에 가까운 UX)

## 우리에게 없는 것

- 띠(말띠 午), 별자리(사자자리)
- 축마다 3~4문장짜리 서술 해설
- 유료 게이트: 1개 7,000 / 3개 16,800 / 5개 24,500 / 10개 35,000원, 미리보기 1개 무료(이름 마스킹)

## 후속 교차검증 (웹 조사 결과와 대조)

별도 웹 조사가 App Store 스크린샷의 **다른 사례**로 같은 규칙을 독립 역산했다 —
최시윤(崔11 · ○14 · 允4)의 수리오행이 木火火, 수리음양이 양음음, 발음오행이 金金土.
4격(18/25/15)에서 획수가 유일하게 역산되고 세 축이 동시에 맞아떨어진다.
우리 실측(金8·10·21 → 金水木)과 완전히 같은 규칙이므로 계산법은 확정으로 본다.

조사가 배제한 대안들: 삼원오행(利/亨/元) → 木土金, 4격 4개 → 金土土水,
자원오행 → 崔은 山부라 土. 모두 실측값과 안 맞는다.
하도(河圖) 계열 환산(1·6=水 …)도 11획이 木인 시점에서 배제된다.

### 어긋났던 점 — 비화 처리 (수정함)

작명왕은 **木火火(상생1+비화1)에 최고 등급**을 주고 본문에도 "상생 관계를 이루고 있다"고
쓴다. 발음오행 金金土(비화+역생)도 마찬가지. 즉 **상극 유무만으로 가르고 비화는 감점하지
않는다**. 우리는 "전부 상생"일 때만 길로 봐서 김대영(金8 垈8 永5 = 金비화金생土)을 보통으로
깎고 있었다.

한국식 발음오행 125칸 배합표도 116칸(93%)이 이 규칙으로 설명된다는 분석이 있어,
`arrangementQualityOf` 로 규칙을 통일했다. 순수 비화(木木木 등 5종)는 소스마다 길흉이
정반대라 길로 올리지 않고 보통에 둔다.

### 미해결

작명왕이 **상극 포함 배열**에 어떤 등급·문구를 주는지는 확인 못 했다.
무료 미리보기는 작명왕이 고른 좋은 이름 하나만 보여주므로 상극 사례가 나오지 않고,
임의 이름을 넣어 보려면 유료 이름풀이(15,000원)를 사야 한다.
